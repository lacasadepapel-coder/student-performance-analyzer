# Student Performance Analyzer

A simple Python project that analyzes student academic performance using data stored in a CSV file.

## Features

* Calculates each student's average marks
* Assigns grades based on performance
* Calculates the overall class average
* Identifies the top-performing student
* Reads student data from a CSV file

## Technologies Used

* Python
* CSV
* File Handling

## Project Structure

* `student_analyzer.py` — Contains the Python program
* `students.csv` — Contains the sample student data

## How to Run

1. Download or clone the repository.
2. Make sure Python is installed.
3. Keep `student_analyzer.py` and `students.csv` in the same folder.
4. Run:

```bash
python student_analyzer.py
```
